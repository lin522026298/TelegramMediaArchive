# 云归档操作记录（公开脱敏版）

本文件记录可复现的工程变更，不记录私人群名、媒体名称、账号、消息编号、绝对用户路径、凭证或个人归档统计。
本机详细部署记录独立保存，不纳入 Git 或发布包。

## 0.1.7：整体审查修复

- 固定单目录单群绑定，禁止误切；Telegram 会话采用根目录级操作系统锁。
- 登录、选群终端纳入 GUI 进程管理；停止始终使用启动时目录；真正退出等待子进程和日志收尾。
- 180 秒无进展检测覆盖增量索引；空队列和活动批次均能发现索引故障，由同一客户端生命周期协调恢复。
- 每次本地清理前重新 cryptcheck；清理中断后本地已不存在时，再检查当前远端逻辑对象大小。
- 每日备份故障独立重试并写入心跳，不终止上传；队列/心跳临时 I/O 故障可重试。
- GUI 显示上传心跳新鲜度、积压、备份状态，提供已配置中转工具的手动恢复入口。
- 恢复要求空目录，核对 manifest 文件集合、大小、SHA-256，再做 cryptcheck；失败不宣称成功，不覆盖已有数据。
- 凭证脚本仅写工具专用目录；临时 rclone 日志始终收尾，最多读取 64 KiB 尾部。
- 固定经过测试的 Windows Python 依赖；源码打包采用 Git 跟踪文件白名单，隐私扫描覆盖源码、历史和 ZIP。
- 部署保留原登录、数据库、云凭证、安全门和 `.part`；维持 20 GiB 预留及不限带宽，不安装服务或开机项。

## 0.1.6：连续恢复

- 磁盘空间恢复后自动继续；网络无进展超时后保留断点、取消同批请求并重连。
- 失败批次不阻塞后续批次；短流不得发布为完整文件。
- GUI 滚动日志、输出限制；冻结 CLI 使用 UTF-8 逐行刷新。
- OpenList 残留 PID 校验避免假“已运行”；不结束其他业务进程。
- 后台维护启动核实独立 Windows 进程生命周期；不把可能的外部终止当作已证实历史原因。

## 0.1.5：磁盘保护

- 下载批次和云反压同步预留 20 GiB；保留 100/50 GiB 队列迟滞。

## 0.1.4：增量处理

- 下载和上传解耦；完整文件经过内容/名称加密、云验证后才清理本地。
- 本地队列轮询和群组增量索引是独立选项。

## 0.1.3：加密云归档

- OpenList 负责网盘授权和挂载，rclone crypt 负责流式内容及文件名加密。
- pilot 验证覆盖回读哈希、cryptcheck、名称加密和多块样本。
- 已验证凭证作用域、UTF-8 API 输入和 Windows 文件名编码一致性。
